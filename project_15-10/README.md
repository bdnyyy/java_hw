Лабораторная работа 1
Описание
Программа для работы с матрицами комплексных чисел.
Поддерживаются следующие операции:
* Сложение матриц
* Умножение матриц
* Деление матриц
* Транспонирование матрицы
* Вычисление определителя
Все данные вводятся через консоль. Последний результат матричных операций сохраняется и может использоваться в следующих вычислениях.
Файлы проекта
Complex.java — класс комплексного числа. Содержит действительную и мнимую части, а также методы сложения, вычитания, умножения и деления комплексных чисел.
Matrix.java — класс матрицы комплексных чисел. Задаёт её размеры и элементы, проверяет условия выполнения операций и содержит методы работы с матрицами. Определитель вычисляется разложением по первой строке.
Main.java — консольное меню, ввод данных, выбор операций и вывод результатов.
